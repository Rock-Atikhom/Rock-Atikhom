## About Me

Data Scientist based in Bangkok, Thailand. I completed a 13-sprint Data Science Bootcamp and apply that foundation to real-world engineering projects — from restaurant analytics dashboards to a real-time CCTV vehicle tracking system running on NVIDIA Jetson Nano.

- Data Science Bootcamp graduate (Batch 09)
- Built a real-time CCTV vehicle tracking pipeline using YOLO + ByteTrack
- Built a restaurant operations analytics dashboard with Streamlit + Plotly
- Interested in computer vision, operational analytics, and AI at the edge
